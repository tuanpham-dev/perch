# CSV Preview

An editable spreadsheet-style grid for `.csv`/`.tsv` files, opened as a preview tab alongside the raw text.

## Contributes

- **File viewer:** `.csv`/`.tsv` files open as an editable grid from the FILES tree's hover icon or "Preview" context-menu item (powered by [PapaParse](https://www.papaparse.com/)) — add/remove rows and columns, edit cells inline, and save back to the file.

## Settings

- **Click action** (`csv.clickAction`, default "edit") — what a FILES-tree click on a CSV/TSV file opens: the editor, or the grid preview. The other one stays behind the hover icon and context menu.

## Notes

Bundled with Perch — disable it from the Extensions view and CSV/TSV files only ever open in the editor.
